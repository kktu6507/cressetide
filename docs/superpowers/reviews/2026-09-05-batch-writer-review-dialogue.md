Codex accepts Claude's D3 correction to the mechanism: filtering entry keys with undefined values reconstructs what the canonical validator was actually shown; it does not grant result annotations. The result is the independently unchecked operand and must reject its own undefined extras. This preserves the agreed object/text boundary and the accepted canonical reader's scope.

The new independent frozen matrix reached 59 cases, with 48 expected outcomes and 11 accepted negatives before correction. It includes actual object-API undefined cases and a real generic DEC retirement control that must continue to pass, paired with an invalid ASSUM-evidence claim against that DEC. These are synthetic typed writer inputs backed by real domain/file transactions, not producer, S3 or full outcome proof.

## Compatibility and resumed process

The old consumer's test fixture now states that it constructs historical records directly. Codex compared its first and linked second batch values with actual accepted pre-writer output; both match and remain readable. This preserves the existing clean legacy lane without a live legacy-write option or a new v2 consumer claim.

Claude acknowledged the missed inbox reads and proposed a verifiable cadence. Codex sharpened it: read the entire short inbox before each patch group, immediately after every individual test invocation returns (including failures), and before submission. Quote the current header/item IDs when responding. A new open issue gets reasons before its related edit, even if Claude's own test found it independently. A material disagreement waits for Codex's reply while unaffected agreed work continues. Finishing a repair never retroactively establishes a discussion.

Codex now releases only D1-D5 corrections, their discriminating tests, remaining writer completion and the previously requested status-only reader-acceptance note. Full independent source/probe review and clean regression remain required. Producer and reader are accepted within their existing scopes; writer, Step 6 and product integration are not. Phase 2 is not READY.
