## Reasons and settled corrections

**A1 — temporary-file ownership.** Claude explained that it intended a fresh unused name, but neither PID naming nor `openSync(...,"w")` established that fact. The old code followed/truncated an existing entry and cleaned by path even if opening failed. It accepted a random suffix, exclusive `wx` creation, at most three EEXIST retries with new names, typed I/O refusal after exhaustion and cleanup only after successful creation. Successful rename clears ownership of the former temporary path. Codex accepted these bounded guarantees against pre-existing entries and accidental collisions; this does not claim universal protection against hostile path replacement between separate filesystem operations.

Claude initially claimed two Promise.all calls could interleave staging. Codex pointed out that all staging after the producer await is synchronous and different repositories have different output paths. Claude withdrew that claim before corrections. Concurrent-call checks are regression controls, not evidence of reproduced interleaving. Collision tests with random naming explicitly declare child-only name/open interception; real filesystem entries and real exclusive-open behavior must remain exercised.

The output ignore file also uses exclusive creation. EEXIST causes revalidation: an existing regular file is preserved, a symlink/non-file refuses, and an entry removed before revalidation triggers another bounded attempt. Three failed attempts refuse; the operation must not proceed without creating or observing the guard. Root ignore bytes remain unchanged.

**A2 — strict new artifact CLI.** Claude accepted that literal `true` for missing values could accidentally select a real task of that name. The new emitter CLI accepts only cwd/base-tree/task flags, each at most once, each with a nonempty nonflag value; base-tree/task are required, cwd defaults to the actual working directory, and bare positionals refuse. All argument failures are E_API_ARGUMENTS before production. Codex found the parser call outside main's catch; Claude agreed to move it inside so failures retain machine JSON on stderr and exit1. Existing default contract-report argument semantics remain unchanged.

**A3 — accurately reached fault points.** Claude acknowledged that its publish-failure test removed the old file itself and reached an early target-type guard, then restored bytes in test cleanup. It proves neither late publication failure nor preservation by the operation. Keep that useful early guard case with an accurate name. Add six genuinely reached late faults in isolated children, path-scope interceptions, require exact fault-hit count and typed cause, and check old bytes plus owned-temp cleanup. No source copying is needed because no shipped source is mutated; Claude accepted direct imports with child-local builtin patches. Collision tests remain separate from owned-temp late-fault tests.
