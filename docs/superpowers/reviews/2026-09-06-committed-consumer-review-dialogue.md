## Findings, reasons and decisions

1. **Historical authority and pre-binding.** Claude had treated B as an input needed only for historical-convergence and resolved pre tags in C. Codex demonstrated clean success with a wrong raw witness, absent/wrong empty witness, symlink, nonexistent tree and own commit type, plus a pre clause existing only in C. Decision: verify exact raw B once on every success, then parse and call the single `validateHistoricalStore` entry point. That function already dispatches v1 to `validateHistoricalLegacyV1`; no caller-maintained branch or current clock is needed. Pre clause/direct Source resolution and Check A use verified B; current activity, expiry and Check B are not charged to pre tags.

2. **REQ scope.** The draft ignored the explicit DP qualifier and selected the first task DP whose terminal or successor matched. Codex reproduced outside-membership/open-qualified-DP borrowing, bare multiple-candidate acceptance and a qualifier on a plain REQ. Claude acknowledged the replacement was incomplete. Decision: qualified form uses the stated DP; bare form requires exactly one `resolvedBy` match within task membership. Charge all five §7 conditions, including resolved status, exact terminal, applicability at the one T0 and actual intent scope ruling. Plain nonexception REQs cannot carry a qualifier.

3. **Direct Sources.** The draft resolved all basis strings, including legitimate ObservationalRefs. An actual domain-written ASSUM with a Source plus plain textual basis passed producer/writer/freshness and failed the consumer. Decision: REQ uses its direct source; DEC/ASSUM follow only plain `S-` basis strings. ObservationalRefs and record-ref objects are not Sources. Actual Source A/B obligations remain.

4. **Candidate groups and typed refs.** Extra candidate/group evidence-ref fields were projected away and accepted; a present nonarray resolutions container leaked TypeError. Decision: absent resolutions in readable prior history contributes no candidates; a present nonarray is a typed refusal. Candidate discovery considers objects naming the claimed T. Every such candidate and its refs must have the exact declared shape before normalization and must satisfy actual subject, acknowledgement, record kind, full digest and membership checks. Unrelated historical group semantics are not newly audited. Equivalent duplicates/permutations remain one meaning; duplicate evidence refs are rejected before the existing deduplicating sort. Only zero candidates may use the independently checked singleton preimage. This cannot fabricate acknowledgement coverage; it is not a general claim that obscuring malformed data can never change acceptance.

5. **Current path checked against history.** Claude independently fixed the partly historical chain, but Codex then showed a same-id later transition with a changed valid acknowledgement still passed. Its proposed B-first walk was challenged because the proof concerns the current path actually used. Decision: verify the initial T id/payload and pre subject; for a clause outcome follow current `effectiveTransition` links, comparing every used transition with B by id/payload, retaining the used successor-clause integrity and final active/applicable outcome checks. For EXPL/deleted cleanup, return after the initial historical T proof: no onward chain is used. Actual EXPL/deleted controls with a later current-only onward transition pass. Clause outcomes using a changed onward transition must refuse.

6. **Verdict.** The draft flattened the head ref, used null for unperformed base work and sorted Source ids by UTF-16 units. Decision: return the agreed recursively frozen typed head ref and exact metadata; absent B has false/null presence/version, present B has true/actual version. Use the shared code-point comparator for deduplicated Source observations. A real non-BMP versus U+E000 control exposed the ordering difference.

The shared raw reader's additional ambiguous-listing refusal is explicitly accepted as a fail-closed strengthening; producer behavior must not be described as literally unchanged in that case. Other protected public contracts, hash formulas and upstream typed errors remain intact.
